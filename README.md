# SWYNEX Internship Task 1: Data Cleaning and Preparation

## Project Overview
This project demonstrates data cleaning and preparation using Python and Pandas on the Titanic dataset.

## Objectives
- Inspect the dataset structure.
- Identify missing values and duplicate records.
- Handle missing values.
- Remove duplicate records.
- Clean text columns.
- Export the cleaned dataset.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Excel

## Files Included
- `titanic_raw.xlsx` – Original dataset.
- `cleaned_titanic.xlsx` – Cleaned dataset.
- `Data_Cleaning_Preparation.ipynb` – Python code and outputs.

## Cleaning Techniques
- Filled missing Age values using the median.
- Filled missing Embarked values using the mode.
- Replaced missing Cabin values with "Unknown".
- Removed duplicate rows.
- Removed extra spaces from text columns.

## Outcome
The Titanic dataset was cleaned and saved for further analysis.
